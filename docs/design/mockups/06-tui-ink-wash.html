    Design notes and decisions for you
    

      

        
What changed from the first draft

        
    
          
  • Panels are separated by whitespace on a lifted surface, not boxes. Borders appear only on the help overlay.
    • 
          
  • One amber accent, used like a seal: the focus mark, the selected row's edge, the active tab and actions waiting on you.
    • 
          
  • The TUI is drawn on an exact cell grid, so nothing overlaps at any size, and the frame scales to fit the page instead of overflowing.
    • 
          
  • Layout switches on columns and rows: wide (≥140 cols), medium (100–139), narrow (<100 cols or <24 rows).
    • 
          
  • Ink wash lives in the palette inside the terminal (design.md §3). The painting is the web skin's still frame, behind the page.
    • 
        

      

      

        
Kept from the plan

        
    
          
  • Progress is verified acceptance criteria (▰▰▱ 2/3), never a percentage.
    • 
          
  • The review gate says whether a change may be committed; a missing or crashed review is "Unavailable", never a pass.
    • 
          
  • Decisions waiting on you sit at the top of the right column; a native prompt offers "open session", never approve.
    • 
          
  • Unknown values read Unknown. Remote workers aren't configured, so they aren't shown.
    • 
          
  • Stale or disconnected data shows a banner and disables approve and reject.
    • 
        

      

      

        
Ruled on 2026-10-24

        
    
          
  1. Chinese is the default and the language switch stays; this reference shows English labels only.
    2. 
          
  2. The console input takes allowlisted commands only; there is no chat.
    3. 
          
  3. Agents show process state and task state together.
    4. 
          
  4. Finalize reads "awaiting decision" until the owner decides.
    5. 
          
  5. The implementation uses Nerd Font glyphs with text fallbacks, not the Unicode glyphs drawn here. See docs/design/t015-tui-design.md.
