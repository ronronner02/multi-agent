# Agent settings and conversation language

Date: 2026-11-09

The owner approved optional request and response fields for local model choices,
the selected reply language, and concise run and task titles. Existing callers
may omit them.

- Model suggestions come from known local model fields and saved choices.
  Suggestions are client-specific identifiers, not a provider availability check.
  Manual entry remains available.
- The selected interface language travels with owner actions. The latest explicit
  choice is stored on the run and reapplied to managed prompts, including direct
  implementer starts. Individual chat messages retain their recorded preference.
  A language-only document confirmation records the choice without adding a
  synthetic conversation message.
- Default specialist controls and option names follow the interface language.
  Owner-edited names and identity instructions remain literal. The lead receives
  bounded expertise excerpts and delegates using an existing compatible profile;
  the assigned specialist receives the complete recorded identity.
- A lead reply can supply a concise leading heading for the run and lead task
  title. Proposed tasks may carry a separate concise title. Complete task briefs
  and conversation replies remain stored.
- The background loop starts at the asset's actual keyframe to reduce seek
  decoding. Browser playback observation remains a separate acceptance check.
