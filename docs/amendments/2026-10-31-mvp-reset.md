# 2026-10-31: MVP reset

**Decided by:** the owner, 2026-10-31.

## Why
- Progress had stalled on T038, the live acceptance of hardened worker isolation. Two producer defects blocked it, and none of its six live invocations were ever used.
- An audit of `main` at 4af0a98 found that even with T038 done, the product could not do its core job:
  - no production code creates a team run or task: `createRun` and `createTask` in `domain/plan-governance.ts` have only test callers;
  - nothing serves the computed patch to the owner;
  - the managed path requires `/etc/multi-agent`, a sudo launcher and the `ma-*` users.
- The setup was tied to the owner's WSL host, and the project is to be handed to another developer.

## Decisions
1. **The MVP defers hardened isolation.** A new setting, `workers.isolation`, has two values:
   - `none`, the default, runs agents as the current user in git worktrees;
   - `hardened` keeps the existing path unchanged.
2. **MVP slices, in order:**
   1. direct launch;
   2. run and task creation (API, `rig team start`, and a "New task" action in the UI and TUI);
   3. result delivery (patch endpoint, `rig team apply`, and a diff view);
   4. `./setup.sh` and a README quick start;
   5. smoke CI.

   Then T033 and the cancellation half of T017.
3. **Deferred:** T038 (parked on `feat/t038-worker-control-isolation-reacceptance`, with its uncommitted work saved as a patch), T018, T046 and macOS support. **Cut:** T024-T030. The Track A/B order and the T038 live grant are retired.
4. **Process changes:**
   - Per-PR checks are the focused tests, a typecheck and the smoke CI. The full suite runs only before a release.
   - Stop rules: twice the estimate, two failed fixes, or 30 minutes without a lead.
   - The orchestrating session reviews every PR. One independent reviewer is added only for credential, worker-file-reading or isolation code.
   - The standards are recorded in `docs/development-standards.md` for reuse in later projects.
5. **UI/TUI restyle:** two directions, drawn from a reference site, go to the owner. Implementation starts only after the owner approves one.
