# Messaging the Human

Ask for the one decision that changes the work. State the observed evidence, the choices that remain, and the
consequence of each choice. Keep the message short enough to answer in one turn and preserve the owner's words
in team chat or the task record.

Do not ask the owner to rediscover repository facts you can inspect. Do not turn a progress update into an
implicit approval request. When the owner answers, record the decision and continue within the accepted boundary.
